О себе

Превращаю хаос технологий в работающие системы

Двадцать с лишним лет я занимаюсь одним и тем же — превращаю хаос технологий в работающие системы. Начинал с вёрстки и серверов, прошёл через трейдинг, дата-саенс, руководство командами и запуск собственных продуктов. Сейчас я тот, кто спокойно смотрит на стек, на бизнес-процессы и на AI-агентов, и говорит: «Вот здесь будет узкое место. А вот здесь — возможность».

Люблю, когда код читается, архитектура дышит, а системы не разваливаются при первом же росте нагрузки. И ещё люблю, когда можно взять новую штуку (будь то LangChain, Rust или очередной harness для AI-агентов), быстро разобраться и сразу встроить её в живую систему.

Практика

AI-агенты и Harness

Активно и прагматично использую AI-агентов в повседневной разработке и построении рабочих процессов. Не «поиграться», а встроить так, чтобы команда реально ускорялась, а качество кода и документации росло.

Harness-подход — AI становится частью инженерной культуры, а не отдельной игрушкой.
Фокус на измеримом ускорении команды и качестве артефактов.

Entropy money
Go · Ed25519 · Mutual Credit
+
GitHub

Консольная утилита на Go для партнёрских взаимозачётов на подписанных контрактах (IOU / mutual credit). Без блокчейна, без майнинга и центрального сервера. Участники выпускают, встречно подписывают и погашают долговые обязательства, обмениваясь ими через файлы. Балансы не хранятся — они вычисляются из набора подписанных контрактов. Чистая криптография (Ed25519 + Argon2id), аудитируемость и понятная модель.

Vanilla option calculator
PyPI · Open Source · Black-Scholes
✪ 150
+
PyPI GitHub

Самодостаточный пакет для анализа ванильных опционов. Чистая реализация модели Black-Scholes-Merton на чистом Python (без NumPy и SciPy): теоретическая цена, греки, портфельный P&L, визуализация и поиск дельта-нейтральной цены. Лежит на PyPI и до сих пор собирает звёзды. Классический пример того, как можно сделать полезный инструмент без лишних зависимостей.

Стек и подход

Инструменты и принципы

Backend

Python (FastAPI, Django REST, LangChain) — основной инструмент. Иногда Go и Rust, когда нужна скорость или просто интересно. Базы: MongoDB, InfluxDB, Redis, PostgreSQL. Real-time — RabbitMQ и WebSockets.

Frontend

JavaScript / TypeScript, Vue.js, Nuxt, Quasar, Vite. HTML5 / CSS3 и PWA. Люблю, когда интерфейс не просто красивый, а ещё и работает офлайн.

Инфраструктура & Подход

Linux, Nginx, Docker, CI/CD. Сначала думаю об архитектуре и данных, потом о коде. Чистые, читаемые реализации. Agile без крайностей. Математический склад ума + гуманитарный взгляд.
